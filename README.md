# Task 3: SQL for Data Analysis

## 📌 Project Overview

This project was completed as part of the Data Analyst Internship.

The objective of this task is to use SQL queries to extract, analyze, and manipulate structured data using the **Supermart Grocery Sales - Retail Analytics Dataset**.

## 📊 Dataset

**Dataset:** Supermart Grocery Sales - Retail Analytics Dataset

The dataset contains grocery sales information such as:

- Order details
- Customer details
- Category
- City and State
- Sales
- Profit
- Discount
- Order Date

## 🛠️ Tools Used

- SQL
- SQLite / MySQL / PostgreSQL concepts
- Excel dataset

## 🔍 SQL Concepts Covered

1. SELECT, WHERE and ORDER BY
2. GROUP BY
3. Aggregate functions – SUM() and AVG()
4. INNER JOIN
5. LEFT JOIN
6. RIGHT JOIN concept
7. Subqueries
8. Average revenue analysis
9. NULL value handling
10. Creating Views
11. Creating Indexes for query optimization
